# 电子元件识别小游戏 ⚡

电子制作社团课堂配套小游戏，帮助同学认识常见电子元件。

## 🎮 三种玩法

| 模式 | 说明 |
|---|---|
| 🔍 元件识别闯关 | 看图 / 听描述，认出它是谁 · 10 题 |
| 🎨 色环读数挑战 | 看四色环算阻值 · 8 题 |
| 📖 元件图鉴 | 先学习，再挑战 |

收录元件：色环电阻、贴片电阻、陶瓷电容、电解电容、电感、二极管、LED、三极管、芯片 (DIP)、排针。

## 🕹 在线游玩

直接打开本仓库的 GitHub Pages 网址即可（见右侧 About 栏）。

## 📁 本地游玩

下载 `index.html`，双击用任意浏览器打开。纯单文件、无依赖、离线可玩。

## 📚 教学要点（答错时的知识卡）

- 电解电容：外壳白条一侧是负极，接反会鼓包甚至爆浆
- LED：长脚正极、短脚负极
- 色环口诀：棕红橙黄绿蓝紫灰白黑，对应 1-0
- 贴片电阻代码：103 = 10×10³Ω = 10kΩ
- 芯片缺口要对准丝印方向
